# 실험 결과 정리 (2026-08-30 갱신)

이 문서는 지금까지 팀이 한 실험을 **다른 팀원의 실험을 자세히 모르는 사람도
따라올 수 있게** 정리한 것이다. 새 실험을 시작하기 전에 이 문서를 읽으면
무엇이 확인됐고 무엇이 남았는지 알 수 있다.

## 0. 먼저 용어부터 (이것만 알면 아래가 전부 읽힌다)

- **베이스 모델** — 우리가 쓰는 모델은 **VAD** (ICCV 2023 논문, 카메라
  영상만으로 경로까지 한 번에 내는 end-to-end 모델)다. 아래에 나오는
  BEVFormer 는 VAD 안에서 지도를 만드는 부품, VADv2 는 VAD 의 후속 논문이다.
- **점수 (L2)** — 모델이 예측한 "앞으로 3초 경로"가 정답 경로와 평균 몇 미터
  어긋나는지. **낮을수록 좋다.** 대회 리더보드도 이 점수로 순위를 매긴다.
  이 문서의 모든 점수는 우리가 떼어놓은 검증 시나리오 39개에서, 대회 채점과
  같은 방식으로 쟀다. 그래서 **문서 안의 점수끼리는 비교 가능**하지만,
  리더보드 점수와의 환산 관계는 아직 모른다 (1차 제출로 확인 예정, 9장).
- **스크리닝 (선별전)** — 본 학습은 비싸다(며칠). 그래서 아이디어를 본
  학습에 넣기 전에 **학습 시나리오 337개 중 113개(1/3)만 뽑아 10 epoch만**
  돌려보는 저렴한 예비 실험을 한다. 점수의 절대값은 본 학습보다 나쁘게
  나오지만, "아이디어 A 가 B 보다 좋은가"를 가리는 데는 충분하다.
- **기준 실험 (base)** — 아무 아이디어도 넣지 않은 VAD 를 스크리닝 조건으로
  돌린 것. 점수 **0.8369**. 새 아이디어는 이보다 **0.12 이상** 좋아야
  채택한다. 0.12 는 "같은 실험을 다시 돌렸을 때 관측된 최대 출렁임
  0.116"(6장)을 상한으로 잡은 잠정값이다.
- **epoch (에폭)** — 학습 데이터 전체를 한 바퀴 도는 단위. 10 epoch = 열 바퀴.
- **BEV (지도)** — 카메라 영상 여러 장을 합쳐 "하늘에서 내려다본 지도"로
  바꾼 것. 모델은 이 지도 위에서 경로를 계획한다. 이하 "지도"라고 부른다.
- **영상 가림 검사 (ablation)** — 학습이 끝난 모델에 일부러 영상을 검게
  지워 넣고 점수가 몇 배 나빠지는지 보는 검사. **많이 나빠질수록 모델이
  영상을 진짜로 보고 운전한다는 뜻**이다. 대회 규정상 "영상을 안 보고 다른
  정보로 컨닝하는 구조"는 실격이라, 보조 정보를 쓰는 모델은 이 검사를
  통과해야 채택한다. **합격선(우리 내규, 운영국 수치 아님): 영상을 지웠을 때
  1.2배 이상 나빠져야 한다.** 주의: 이 배율은 학습량이 비슷한 모델끼리만
  비교할 수 있다 (많이 학습된 모델일수록 영상 의존이 커서 배율도 커진다.
  전체 데이터 모델은 8.2배, 스크리닝 모델은 1.5배 수준 — 부록 C).
- **추론 시간 (T_infer)** — 한 번의 판단에 쓰는 프레임 3장을 처리하는 시간의
  합계. 채점 환경에서 100ms 를 넘으면 감점이 붙는다 (감점 폭은 공지에 없어
  "안 넘기는 것"을 원칙으로 한다).

## 1. 한눈 요약 (8/30 밤 기준)

이번 주 스크리닝으로 **아이디어 5개를 기준 실험과 같은 조건에서 겨루게
했다.** 결과: **1개는 어떤 해석으로도 채택 확정, 2개는 채택(단 6장의 재검증
조건부), 1개는 보류, 1개는 기각.**

| 순위 | 아이디어 (한 줄 설명) | 점수 | 판정 |
|---|---|---|---|
| 1 | **목표점 힌트** — 목표점을 지도 만드는 단계에 힌트로 줌 | **0.5306** | **채택 확정** (3장) |
| 2 | **지도 해상도 상향** — 지도를 100×100 → 150×150 으로 | 0.6713 | **채택** (4장, 6장 조건부) |
| 3 | **경로 사전** — 대표 경로 4096개 중 영상으로 골라 다듬기 | 0.6869 | **채택** (5장, 6장 조건부) |
| 4 | 차선 이탈 벌점 — 학습 때 차선 밖 경로에 벌점 | 0.7500 | 보류 (6장) |
| 5 | 층수 2배 (deep6) — 지도·경로 계산 층을 3→6층으로 | 0.7191 | **기각** (8장) |
| - | 기준 실험 (아이디어 없음) | 0.8369 | 비교 기준 |

세 줄 결론:

1. **1위(0.5306)는 1/3 데이터만 쓰고도, 전체 데이터로 학습했던 기존 최고
   기록(0.5537)을 넘었다.** 전체 데이터 + 긴 학습(본 학습)에 실으면 더
   오를 여지가 크다.
2. **결합은 두 번 모두 실측 기각됐다** (1+2 해상도 결합 0.7228,
   1+3 앵커 결합 0.6478 - 모두 챔피언 단독보다 나쁨, 8장). 원인도 서로
   달라서(요동/손실 간섭), 남은 기간의 제출 라인은 **목표점 힌트 단독
   계열로 확정**한다.
3. 단, 6장의 미해결(기준 실험이 유독 나쁘게 나왔을 가능성)이 판정되면
   **2·3위의 이득 폭은 다시 계산한다.** 1위는 어느 해석으로도 기준을
   넘겨서 결론이 안 바뀐다.

참고 - 리더보드(9/2, 제출 26건 / 약 18팀): 1위 0.1305 / 2위 0.1376 /
3위 0.1424 이고 6위(0.1526)까지 촘촘하다. **입상(3위 이내) 기준선은
~0.142.** 금지 구조 팀들이 코드 심사에서 걸러지기 전의 수치고, 우리 검증
점수와의 환산 관계는 1차 제출로 확인한다. 우리 전략은 "심사에서 살아남는
구조"로 점수를 쌓는 것이다.

## 2. 배경: 왜 이 방향들이었나

출발점이 된 사건이 두 개 있다.

**사건 1 — 컨닝 구조 제출을 두 번 직전에 멈췄다 (8월 3~4주, 폐기 실험 4건).**
대회는 "5초 뒤 차가 있어야 할 목표점"을 입력으로 준다. 이걸(그리고 차량
속도를) 경로 결정부에 직접 넣었더니 점수가 크게 올랐고, 제출 직전까지
갔었다. 그런데 영상 가림 검사를 해보니 **영상을 지워도 점수가 거의 안
나빠졌다** (0.85~1.13배 — 목표점 모델은 지우니 오히려 좋아졌다). 모델이
영상을 안 보고 목표점만 보간해서 운전하고 있었던 것이다. 이런 구조는
운영국이 금지를 확정했다 → 속도 모델과 목표점 모델 2건 모두 제출 전에
폐기. 교훈과 상세 수치는 8장.

**사건 2 — 운영국 답변으로 합법 통로 두 개가 열렸다 (8/28).**
- "목표점을 경로 결정부가 아니라 **지도(BEV)를 만드는 단계의 조건 입력**으로
  쓰는 간접 방식은 허용" → 3장(목표점 힌트)의 근거.
- 타 팀 질의 답변에서 "**학습 데이터로 만든 고정 대표 경로(앵커) + 영상 기반
  선택/보정**은 허용" → 5장(경로 사전)의 근거.

즉 "목표점의 가치는 실증됐는데(폐기 실험에서 점수 0.33까지 나왔다) 쓰는
방법이 불법이었던" 상황에서, 합법적으로 쓰는 길이 공식 확인된 것이다.
여기에 규정 위험이 아예 없는 순수 영상 개선 두 가지(지도 해상도, 층수
2배)를 더해 같은 조건으로 겨루게 했다.

## 3. 채택 1위 — 목표점 힌트 (점수 0.5306, 메인컴)

**왜 시도했나.** 목표점은 대회가 주는 합법 입력이고, 정보 가치가 크다는 게
폐기 실험에서 이미 실증됐다. 문제는 "어디에 넣느냐"였다. 경로 결정부에
직접 넣으면 컨닝(사건 1), 지도 형성 단계에 넣으면 합법(사건 2). 그래서
합법 위치에 넣되, 컨닝 방지 장치를 함께 달아 시도했다.

**어떻게 했나.** 목표점 좌표(숫자 2개)를 작은 신경망으로 변환해서, 지도를
만들 때 더해준다. 경로 결정부는 여전히 지도만 본다. 컨닝 방지 장치로
**학습 중 절반의 확률로 목표점을 일부러 지웠다** (condition dropout 0.5).
"목표점이 없을 때도 영상만으로 운전할 수 있어야 한다"를 학습 내내
강제하는 것이다.

**결과가 어땠나.** 점수 **0.5306** — 기준(0.8369)보다 0.30 좋다. 1/3
데이터만 쓰고도 전체 데이터 기존 최고(0.5537)를 넘었다. 학습 진행에 따라
점수도 꾸준히 좋아졌다 (4에폭 0.751 → 7에폭 0.578 → 10에폭 0.531).

**왜 채택인가 (검증).** 영상 가림 검사에서 영상을 지우니 점수가 **1.22배**
나빠져 합격선(1.2배)을 넘었다. 이 수치를 읽는 법: 같은 학습량의 순수 영상
모델이 같은 검사에서 1.55배다. 즉 이 모델은 순수 영상 모델보다 영상 의존이
낮아지긴 했지만, 폐기했던 컨닝 모델들(0.85~1.13배: **영상을 지워도
거의 멀쩡**)과는 명확히 다르게 영상이 여전히 일하고 있다. 구조 자체가
운영국 허용 답변과 일치하므로 규정 위험도 낮다. 검사 기록은 2차 심사(코드
심사) 방어용으로 보관했다. 채택 폭(0.30)이 커서 6장의 미해결과 무관하게
결론이 유지된다.

**어떻게 발전시키나.**
1. 지도 해상도 상향과 결합 (tb150, 메인컴에서 진행 중, ~9/1 밤)
2. 지우는 확률(0.5)을 0.6~0.7 로 올려 영상 의존을 더 살릴 수 있는지 —
   합격선 여유(1.22배)를 키우는 방향의 실험 후보
3. 최종적으로 본 학습(전체 데이터, A100)에 탑재

## 4. 채택 2위 — 지도 해상도 상향 (점수 0.6713, 서브컴)

**왜 시도했나.** 지도(BEV)는 원래 100×100 칸이고 한 칸이 60×30cm 다.
150×150 으로 올리면 한 칸이 40×20cm 가 되어 (칸 수 2.25배) 차선과 주변
차의 위치가 더 정확해진다. 이런 해상도 상향은 지도 부품(BEVFormer 계열)
에서 꾸준히 효과가 보고돼 있고, **영상 처리만 바꾸는 것이라 규정 위험이
전혀 없다.**

**어떻게 했나.** 설정 파일에서 지도 크기와 얽힌 값 4곳(지도 크기, 회전
중심, 위치 부호화, 데이터 파이프라인)을 함께 150 으로 바꿨다. 하나라도
빼먹으면 크기가 안 맞아 죽거나 조용히 어긋나는 부분이라 설정에 주석으로
남겨뒀다.

**결과가 어땠나.** 점수 **0.6713** — 기준보다 0.17 좋아 채택 기준(0.12)을
넘었다.

**왜 채택인가.** 효과가 크고, 순수 영상 개선이라 컨닝 위험이 원천적으로
없다 (그래서 영상 가림 검사도 필요 없다). 단, 이득 폭 0.17 은 6장의
미해결이 "기준 실험이 유독 나빴다" 쪽으로 판정되면 다시 계산한다.

**주의점 하나.** 지도가 커진 만큼 계산이 무거워져 추론 시간이 늘었다.
서브컴(GPU 가 느린 편) 기준 3프레임 합계 295ms(프레임당 98ms)로 감점선
근처다. 채점 환경은 이보다 훨씬 빠를 것으로 보지만(같은 모델이 4080 에선
3배 이상 빠르다), **제출 전에 4080 에서 재측정이 필수**다.

**어떻게 발전시키나.**
1. 목표점 힌트와 결합 (tb150, 진행 중)
2. 본 학습 전에 "해상도 200 은 시간 예산 안에 들어오는가"를 재보고 판단

## 5. 채택 3위 — 경로 사전 (점수 0.6869, 4080)

**왜 시도했나.** 원래 VAD 는 경로를 백지에서 그려낸다. 대안으로, **학습
데이터에 실제로 나온 주행 경로들을 대표 경로 4096개로 미리 요약해두고
(경로 사전), 영상을 보고 그중 하나를 고른 뒤 미세 조정하는** 방식이 있다
(후속 논문 VADv2 의 방식). 8/28 운영국이 타 팀 질의에 이 구조를 허용한다고
명시해서 공인 패턴이 됐다. 시도 전에 계산으로 천장을 재봤다: 4096개 중
매번 정답에 가장 가까운 것을 고르기만 해도 **우리 검증셋에서 점수 0.0765**
— 우리 전체 데이터 최고 기록(0.5537)의 1/7 수준이다. 즉 "고르는 눈"만
좋아지면 **천장이 매우 높은** 방식이다. 또 예전에 "목표점으로 3개 후보 중
고르기"가 효과 없던 것(8장)도 "후보가 4096개면 다르지 않을까"로 이어졌다.

**어떻게 했나.** ① 학습 데이터의 주행 경로 10만 개를 군집화(k-means)해서
대표 경로 4096개를 뽑았다 (학습 데이터만 사용 — 테스트 데이터는 규정상
사용 불가라 코드에 출처를 명시했다). ② 모델에 브랜치 두 개를 달았다: 영상
특징으로 4096개 각각에 점수를 매기는 **선택기** + 고른 경로를 영상 특징으로
미세 보정하는 **조정기**. ③ 기존의 백지 경로 생성도 학습에는 그대로 남겨
안정성을 유지했다.

**결과가 어땠나.** 점수 **0.6869** — 기준보다 0.15 좋다. 선택기가 실제로
학습됐음을 손실 곡선으로 확인했다 (무작위 수준 4.16 에서 1.79까지 하강).

**왜 채택인가.** 영상 가림 검사에서 **순수 영상 모델과 완전히 같은
1.55배**가 나왔다 — 고르는 것도 다듬는 것도 전부 영상이 하고 있다는 뜻이라
규정 방어가 가장 깔끔한 채택안이다. 추론 시간도 3프레임 합계 82.7ms(4080)
로 기존과 같다. 단, 이득 폭 0.15 는 4장과 마찬가지로 6장 판정 후 재계산
대상이다.

**어떻게 발전시키나.** 갈 길이 멀다는 게 곧 여지다: 현재 0.6869 는 천장
0.0765 는커녕 "목표점만으로 고르기"의 상한(0.60, 부록 C)에도 아직 못
미친다. **선택기 학습 개선이 최우선**이다 — 정답 하나만 맞히기 대신 가까운
후보 여러 개에 부분 점수 주기(soft label), 상위 후보 평균 내기(top-k),
조정기 강화, 그리고 다른 채택안과의 결합.

## 6. 보류 1건 + 미해결 1건 (그리고 이게 채택 판정에 미치는 영향)

**보류 — 차선 이탈 벌점 (0.7500).** 학습 때 "예측 경로가 차선을 벗어나면
벌점"을 주는 손실을 켰다 (VAD 원 논문에는 있는데 우리 설정에서 꺼져
있었다). 기준보다 0.087 좋게 나왔지만 채택 기준(0.12)에 못 미치고, 이
크기가 진짜 효과인지 우연 변동인지 아직 가릴 수 없어 보류.

**미해결 — 4 epoch 미스터리.** 우연 변동의 크기를 재려고 기준 실험을 한 번
더 돌렸는데, 실수로 4 epoch 만 돌았다. 그런데 이 4 epoch 짜리(0.7209)가
10 epoch 짜리 기준(0.8369)보다 **좋았다.** 해석은 두 가지:

1. **과적합** — 1/3 데이터에서는 오래 돌리면 오히려 나빠진다. 그렇다면
   기준 실험의 0.8369 는 "유독 나쁘게 나온 값"이고, 스크리닝도 4 epoch 로
   줄여 GPU 시간을 60% 아낄 수 있다.
2. **우연** — 같은 실험도 돌릴 때마다 이만큼 출렁인다. 그렇다면 채택
   기준을 더 높여야 한다.

지금까지의 증거는 1번에 기운다: 연속 저장본 간 변동 실측이 0.03 수준이라
0.116 차이를 우연으로 보기엔 크고, 1위 모델은 10 epoch 내내 좋아지기만
했다(과적합 없음 — 단 이건 조건 입력 모델 얘기고 기준 모델은 다를 수 있다).

**정직하게 말하면, 이 판정에 채택 2·3위의 운명이 걸려 있다.** 만약 공정한
비교선이 0.8369 가 아니라 0.7209 쪽이라면:

| | 기준을 0.8369 로 볼 때 | 기준을 0.7209 로 볼 때 |
|---|---|---|
| 목표점 힌트 0.5306 | 이득 0.30 → 채택 | 이득 0.19 → **여전히 채택** |
| 해상도 150 0.6713 | 이득 0.17 → 채택 | 이득 0.05 → **재검증 필요** |
| 경로 사전 0.6869 | 이득 0.15 → 채택 | 이득 0.03 → **재검증 필요** |

**8/31 갱신 - 판정 실험 ②의 결과가 나왔다.** 해상도 150 을 4 epoch 로
다시 돌린 결과 (모든 평가는 재실행으로 재현 확인):

| 시점 | 점수 |
|---|---|
| 3 epoch 끝 | 0.6832 |
| 4 epoch 끝나기 425걸음 전 | **0.5215** |
| 4 epoch 끝 (최종) | **0.6260** |

세 가지를 배웠다:

1. **짧은 학습 우위는 재확인됐다.** 같은 구조의 4 epoch 최종(0.6260)이
   10 epoch 최종(0.6713)보다 0.045 좋다. 다만 차이 폭은 base 쌍(0.116)보다
   작아서, base 의 0.8369 에는 "불운"도 섞여 있었을 가능성이 남는다 -
   최종 확정은 여전히 쌍둥이 실험 몫이다.
2. **4 epoch 스케줄은 막판이 "뜨겁다".** 학습 종료 시점의 학습률이
   10 epoch 스케줄(1.0e-5)보다 3배 높아서(2.9e-5), 마지막 몇백 걸음
   사이에도 점수가 0.1 씩 출렁인다 (0.5215 -> 0.6260). 실험끼리 비교할
   때는 반드시 **최종 체크포인트끼리** 비교해야 공정하다.
3. **이 출렁임은 역이용할 수 있다.** 검증 점수로 여러 체크포인트 중 최선을
   골라 제출하는 것은 합법적인 표준 기법이다 (검증셋은 우리가 학습
   데이터에서 떼어낸 것으로, 테스트 정보를 쓰지 않는다). 위 표만 봐도
   저점(0.5215)과 최종(0.6260)의 차이가 0.1 - **제출 전 후보 체크포인트
   전수 평가를 표준 절차로 삼는다.**

판정 실험 두 개가 돌고 있다: ① **쌍둥이 실험** (4080) — 기준과 완전히 같은
설정·같은 GPU 로 10 epoch 을 다시 돌려, 0.8369 이 재현되는지(우연 변동의
크기)를 직접 잰다. ② **해상도 150 을 4 epoch 로 재실행** (서브컴) — 짧은
학습이 다른 아이디어에서도 이기는지 확인한다. 결과에 따라 채택 기준
(잠정 0.12 = 관측된 최대 출렁임 0.116 의 반올림)도 확정한다.

## 8. 폐기·기각된 실험들 — 배운 것 (상세 수치는 부록 C)

- **속도/목표점을 경로 결정부에 직접 입력 (4건)** → 점수는 오르지만 영상
  가림 검사에서 0.85~1.13배 (= 영상을 안 봄). 운영국 금지 확정 + 전부 폐기.
  **교훈 1: 학습 손실이 유난히 빨리·깊게 떨어지면 컨닝 신호다.**
  **교훈 2: 보조 정보를 쓰는 모델은 반드시 영상 가림 검사 후에 제출을
  논한다.** 이 원칙 덕에 실격성 제출을 2건 막았다.
- **dropout 0.7 변형 (d07, 기각 - 9/4).** 목표점을 학습 중 70% 확률로
  지우면 영상 의존이 강해질 것으로 기대했으나 정반대였다. 점수는 0.5635
  (챔피언 0.5306 과 비슷, 단 batch 4 로 달랐음)인데 **영상 가림 검사가
  0.97배 - 영상을 지워도 점수가 오히려 좋아졌다** (챔피언 d0.5 는 1.22배
  통과). 해석: 목표점이 학습 중 드물게 등장할수록 "등장했을 때 절대적으로
  신뢰"하는 쪽으로 수렴한 것으로 보인다 (추론 시엔 목표점이 항상 있으므로
  영상이 무시됨). **교훈: 이 계열의 영상 의존은 dropout 값에 민감하고
  방향도 직관과 다르다. 전체 데이터 본 학습 모델도 제출 전 ablation 을
  반드시 통과해야 하며(기존 규칙 재강조), 통과 실패 시 dropout 재탐색이
  필요하다.** 채택 세팅은 dropout 0.5 유지.
- **결합 2호: 목표점 힌트 x 경로 사전 (ta, 기각 - 9/4).** 곡선은 안정적으로
  수렴했지만(0.737 -> 0.674 -> 0.648) 최종이 챔피언 단독(0.5306)보다 0.12
  나쁘다. 진단 평가로 원인을 특정했다: 같은 체크포인트에서 **회귀 출력만
  평가해도 0.7074** - 즉 앵커 선택기가 병목이 아니라, **앵커 브랜치의 추가
  손실(4096 분류 + 잔차 회귀)이 본 계획 학습을 방해**했다 (다중 과제 간섭).
  영상 가림 검사는 1.52배로 깨끗해 규정 문제는 없다.
  **교훈: 결합 실패 두 건의 원인이 서로 다르다** - tb150 은 최적화 불안정
  (요동), ta 는 손실 간섭 (안정적이되 하향 수렴). 어느 쪽이든 "채택안을
  겹치면 더 좋아진다"는 가정은 이 대회 기간 안에서는 폐기한다. 앵커 축은
  손실 가중치 완화·2단계 학습 등 전용 튜닝 과제로 보류.
- **결합 1호: 목표점 힌트 x 해상도 150 (tb150, 기각 - 9/2).** 단독 1위
  (0.5306)와 2위(0.6260)를 합치면 더 좋아질 것으로 기대했으나, 10 epoch
  완주 결과 **0.7228 - 양쪽 단독보다 나쁘다.** 학습 내내 epoch 간 점수가
  +-0.3 씩 요동쳤고(단독 목표점 힌트는 한 번도 후퇴 없이 수렴), 최고
  시점(3에폭 0.6204)조차 단독들에 못 미쳤다. 두 방법이 같은 곳(지도
  형성)을 건드려 최적화가 불안정해진 것으로 추정한다.
  **교훈: 채택안이라도 결합은 실측으로만 판정한다.** 전체 epoch 곡선은
  부록 C.
- **층수 2배 (deep6, 기각 - 8/31 평가).** 지도와 경로를 계산하는 층을
  3층에서 6층으로 늘렸다 (VAD 원 논문의 큰 모델이 6층이다. 메모리가 커서
  A100 에서만 돌릴 수 있었다). 결과 0.7191 - 기준보다 0.118 좋지만 채택
  기준(0.12)에 근소 미달이고, 계산량이 커져 추론 시간이 프레임당 76.9ms
  (A100 기준. 원래 모델은 4080 에서 27.6ms)로 감점선을 위협한다. **이득은
  작고 비용은 큰 축**이라 기각. 같은 GPU 예산이면 해상도 상향(4장)이 이득도
  크고 추론도 덜 무겁다.
- **목표점으로 3개 후보 중 선택** → 합법이지만 효과 없음 (0.5537→0.5690).
  후보가 좌/우/직진 3개뿐이면 고를 여지가 없다. 이 관찰이 "후보를 4096개로
  늘리면?"이라는 5장으로 이어졌다.

### 본 학습 시간 실측과 재배치 (8/31)

A100(Colab)에서 전체 데이터를 실측했다: 12,638 걸음/epoch x 2.08초 =
**epoch 당 7.3시간.** 원래 계획했던 40 epoch 은 12일이 걸려 **불가능**하다.

의외의 발견: 4080 이 이 Colab A100 보다 샘플당 1.4배 빠르다 (0.18 vs
0.26 초/샘플 - Colab 은 GPU 가 좋아도 데이터 공급이 느리다). A100 의 진짜
가치는 속도가 아니라 메모리(40GB)다. 따라서:

| 본 학습 후보 | 머신 | epoch 당 | 10 epoch |
|---|---|---|---|
| 목표점 힌트 (가벼움) | 4080 | ~5시간 | ~2일 |
| tb150 결합 (무거움) | 4080 | ~10-12시간 (실측 필요) | ~4-5일 |
| 위 무엇이든 | A100 | 1.4배 느림 | 병렬 변형·앙상블용 |

epoch 수는 "많이"가 아니라 "epoch 마다 저장하고 검증 점수로 고른다"로
접근한다 (6장의 체크포인트 선택 전략). 구성 확정은 tb150 곡선을 보고 9/1.

**tb150 조기 곡선** (서브컴 원격 평가 체인, 진행 중):
epoch1 0.8953 -> epoch2 0.9189 -> epoch3 **0.6204** -> (진행 중).
3 epoch 만에 해상도 150 단독 최고(0.6260)를 넘었다 - 두 채택안의 결합에
파괴적 상호작용은 없다.

```
8/31~9/1  스크리닝 전 결과 수합 -> 6장 판정 -> 채택 기준 확정
9/1~2     본 학습 구성 결정 (A100, 전체 데이터, 채택안 탑재. epoch 수는
          "전체 데이터 1 epoch 소요 시간"을 재서 시간 예산에 맞춰 정한다)
~9월 초    1차 제출 - 검증 점수와 리더보드 점수의 환산 관계도 이때 확인
9/18~     버퍼: 제출 검증, FLOPs 기록, 2차 심사 자료(도커/체크포인트/코드
          + 영상 가림 검사 기록)
```

본 학습은 **같은 config 를 3개 GPU 에서 병렬로 돌리는 3-시드 체제**다
(A100/4080/메인컴 - 하드웨어·비결정성만으로도 실행 간 차이가 0.1 수준임을
base 쌍에서 실측했다). 완주 후 3 실행 x 10 epoch = 최대 30개 체크포인트를
검증 점수로 골라 제출한다 ("모델 출력 중 선택" - 운영국 허용 명시).
각 제출 후보는 ablation 통과 필수 (d07 사례: 점수는 좋아도 지름길일 수 있다).

제출은 **총 5회 제한, 현재 0회 사용.** 계획: 1차(환산 확인) → 본 학습
결과 2~3회 → 마지막 버퍼 1회.

### 다음 학습 결정 (9/8) — 7 epoch 완전 어닐링

두 시드 모두 "10 epoch 스케줄의 5~6 epoch 정점 후 과적합" 이고, 스크리닝에서도
4ep 완주가 10ep 완주보다 좋았다. 남은 GPU 시간(4080 유휴, A100 유휴, 메인컴 9/9)에
가장 근거 있는 한 수는 **코사인이 7 epoch 에서 끝나는 같은 config**
(`exp_full_tgtbev_ep7.py`, iter 체크포인트 40개 보존)이다. 4080 36h → 9/10 완료.
A100 은 같은 config 를 batch 5 로(4080 과 조건을 맞춰 순수 반복 시드).
기각한 것: 시드 간 출력 앙상블(T_infer 3배 → 2차 점수 ×1.73), 동일 목적 저lr 추가
학습(과적합 진행), tb150/deep6 본학습(시간·T_infer), 목표점 3-후보 선택(실측 무효).
비용 0 실험: 같은 시드 인접 epoch 가중치 평균(`tools/avg_ckpt.py`, e5+6+7 / e5+6 /
e6+7)을 서브컴에서 평가 중 — 이득이 노이즈(0.03)를 넘을 때만 채택, ablation 재통과.

## 11. 1차 제출 결과 — 검증 점수와 리더보드의 환산 관계 (9/8)

9/8 15:2x, 4080 시드 epoch_6(10장)을 제출했다 (5회 중 **1회 사용**, zip 안
`submission.json`, SHA-256 469c0e4e…).

| | 1s | 2s | 3s | L2_avg |
|---|---|---|---|---|
| 우리 검증셋 (39 시나리오, 제출과 같은 추론 설정) | 0.221 | 0.362 | 0.537 | **0.3731** |
| 리더보드 (테스트 1,125 clip) | 0.199 | 0.340 | 0.527 | **0.3553** |

- **환산 관계: 리더보드 ≈ 검증 × 0.95.** 사실상 같은 값이다. 우리 검증셋이
  테스트를 잘 대표하고 있고, 검증 점수 개선분이 그대로 리더보드에 옮겨진다고
  보면 된다. 앞으로 체크포인트 선택은 검증 점수만으로 해도 된다.
- FLOPs cut-off 통과(459G, `cutoff: true`).

**리더보드 현황 (9/8 15:28, 총 35건)**: 1위 0.092, 3위 0.138, 10위 0.184. 우리 0.3553.

환산이 1:1 이므로 입상선(3위 0.138)은 **검증 L2 0.14 수준**을 뜻한다. 우리가
측정한 참조점과 대조하면: 순수 운동학 외삽 0.414, 목표점 Hermite+운동학 0.166,
목표점 단독 선택 상한 0.60, 목표점을 planner 에 직접 넣은 폐기 모델 0.331.
즉 상위권 점수는 목표점·자차 상태를 궤적 생성에 직접 쓰지 않고는 나오기
어려운 값이며(0장 "리더보드를 그대로 믿지 말 것"), 코드 심사(2차)에서 어떻게
걸러지느냐가 우리 순위를 결정한다. 우리 방침(심사 생존 우선)은 유지한다.
