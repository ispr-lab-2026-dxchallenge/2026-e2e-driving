## 2~3. 추론 설정 (학습 불필요 — 전부 실측 확정)

- 오프셋: `-10,-5,0` 최적. 배포 기본 7프레임은 L2 2배 나쁘고 2.4배 느림
- **이력 프레임 BEV-only** (8/25 운영국 허용): T_infer -21%, **L2 소수점 4자리까지 동일**
- **fp16 추론** (허용): T_infer -19%, L2 변화 없음
- 합계: 3060 에서 420→244ms, **4080 에서 81.7ms** — 채점 HW 에서는 더 빠를 것
- `etri_test_submit.py` 는 두 최적화가 기본 켜짐. T_infer 는 제출 코드로 측정되므로 중요

## 4~7. 보조 정보를 planner 에 넣는 계열 — 전부 폐기 (중요 교훈)

세 실험이 같은 패턴으로 실패했다.

| 입력 추가 | 학습 plan_reg (낮을수록) | 영상 제거 시 L2 |
|---|---|---|
| 없음 (베이스라인) | 0.0323 | **8.2배 악화** (영상을 봄) |
| 속도 | 0.0193 | 1.13배 (안 봄) |
| 목표점 | **0.0126** | **0.85배 — 영상을 지우니 좋아짐** |
| 목표점+속도 | 0.0168 (ep3) | (측정 전 구조 금지로 중단) |

**교훈: 학습 손실이 유난히 빨리/깊게 떨어지면 지름길 학습의 신호다.**
5초 목표점은 3초 궤적과 거의 결정적으로 상관되어, planner 가 목표점 보간으로
수렴하고 영상 경로는 학습 신호를 잃는다. 영상 특징은 잡음이 되어 오히려 해롭다.
(동일 현상 참고: "Is Ego Status All You Need..." CVPR 2024)

단, **목표점 정보의 가치 자체는 실증됐다**: 목표점 모델 val 0.331 (베이스라인
대비 -0.22). 합법적으로 꺼낼 방법이 확보되면 리더보드 상위권 수준이다.

## 10. base2 반전 — 4 epoch 이 10 epoch 을 이겼다 (8/29)

노이즈 보정용 base2 가 사고로 **4 epoch** 으로 돌았다 (config 의
total_epochs=4 를 수정된 train_watch 가 그대로 존중; 지시문에 EPOCHS=10
누락). 그런데 결과가 정보다:

| 실행 | epoch | L2_avg (1s/2s/3s) | 비고 |
|---|---|---|---|
| base (기준) | 10 | **0.8369** | 4080, seed 0 |
| base2 (동일 설정) | 4 | **0.7209** (0.398/0.701/1.064) | 4080, seed 0, lr 4ep 로 annealing |

**4ep 가 0.116 더 좋다.** 해석은 두 갈래이고 아직 못 가른다:

1. **1/3 데이터에서 10ep 는 과적합** — 그럼 스크리닝을 4ep 로 줄여야
   한다 (GPU 시간 60% 절약, 판별력도 상승)
2. **실행 간 노이즈가 ±0.1 수준** — 그럼 현행 채택 기준 Δ≥0.08 은
   너무 낮다. plan_bound 잠정 채택(Δ-0.087)도 무효가 된다

가르는 방법 (추가 학습 0원): 남아있는 체크포인트 다중 평가.
- base@{4,8,9}ep vs base@10ep: 한 실행 안의 epoch 별 흔들림 + 과적합 곡선
- base2@3ep vs base2@4ep: 4ep 실행의 흔들림
- bev150@{8,9,10}ep (서브컴): 독립 실행의 흔들림 재확인

**그때까지 모든 스크리닝 판정 보류. 잠정 채택 기준 Δ≥0.12 로 상향.**
진행 중인 실험(트랙 T/V, deep6, bev150)은 10ep 그대로 완주시켜 비교
가능성을 유지한다.

### 1차 판별 데이터 도착 (8/30 아침)

**bev150 스크리닝 완료 (서브컴, 10ep): L2_avg 0.6713** (0.358/0.653/1.003)
- 기준 0.8369 대비 **Δ-0.166. 현재까지 최고.** 잠정 상향 기준(0.12)도 크게
  통과하므로 노이즈 문제와 무관하게 채택 유력.
- 순수 비전 확장 축(해상도)이라 ablation 불요, 지름길 위험 없음.
- 주의: T_infer 98.3ms/프레임 (3060 기준, 100ms 직전). 3060 이 느린 걸
  감안해도 BEV 150 은 무겁다. **제출 전 4080 에서 재측정 필수.**

**인접 체크포인트 흔들림 실측**: iter_86000 (0.7030) vs iter_87000 = 최종
(0.6713), 1000 iter 간격에 Δ0.032. 이전 추정(±0.08)보다 작다. 이 척도로
보면 base(0.8369) vs base2@4ep(0.7209) 의 0.116 차는 순수 노이즈로 보기
어렵고 **과적합 쪽에 무게**가 실린다. 확정은 아래 재실험으로.

**진행: bev150@4ep 재실험** (서브컴, 8/30 10:02 시작, ~18h)
- 4ep-annealing 이 최강 축에서도 10ep 를 이기는지 직접 검증.
- 새 훅 적용 첫 실행: epoch_1~4.pth 가 전부 남아 epoch 곡선이 나온다.

## 11. 트랙 T 판정: 채택 (8/30 저녁)

**tgtbev (목표점->BEV 조건 + dropout 0.5, 10ep): L2_avg 0.5306**
(0.278/0.512/0.802) - 기준 0.8369 대비 Δ-0.306. **전 실험 1위.**
1/3 데이터로 전체 데이터 베이스라인(0.5537)까지 넘었다.

### 채택 근거: 영상 ablation (같은 프로토콜의 기준 모델과 비교)

| 검사 | tgtbev | plan_bound (순수 비전 기준) |
|---|---|---|
| 영상 zero | **1.22배** 악화 | 1.55배 악화 |
| 영상 shuffle | 1.01배 | 1.16배 |

- 순수 비전 모델조차 zero 1.55배/shuffle 1.16배에 그친다. shuffle 은
  같은 도로의 다른 프레임이라 원래 약한 검사다.
- tgtbev 는 의존도가 **낮아졌지만 붕괴는 아니다** (경고선 1.2배 위).
  금지 판정을 받은 직접 입력 실험(#4~7)의 0.85~1.0배 붕괴와는 다르다.
- zero 시 절대 성능 1.29 (기준 모델은 2.56): 영상이 죽어도 목표점
  조건이 합리적 사전확률을 주는 것 - 허용 구조가 의도한 동작이다.
- 2차 심사 방어 기록: ablation.log 2건 보존 (tgtbev, plan_bound).

### 학습량 곡선 (keep 체크포인트, 과적합 없음)
